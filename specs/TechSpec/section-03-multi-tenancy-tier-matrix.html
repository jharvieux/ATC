3.5 Trial Period ¶

All paid tenant tiers get a 30-day trial. The trial starts at activation (not at signup), so a sub-host whose review takes a week still gets full 30 days when they’re approved.

3.6 Tenant Resolution Logic ¶

// apps/main/src/middleware.ts (excerpt)

async function resolveTenant(req: NextRequest): Promise<Tenant | null> {

const hostname = req.headers.get(‘host’);

// Platform primary domain → platform context

if (hostname === PLATFORM_PRIMARY_DOMAIN) return null;

// Subdomain on platform

const subdomainMatch = hostname.match(new RegExp(^([a-z0-9-]+).PLATFORMDOMAINREGEX));

if (subdomainMatch) {

return await getTenantBySlug(subdomainMatch[1]);

}

// Custom domain

return await getTenantByCustomDomain(hostname);

}

3.7 Multi-Tenant Identity ¶

A single OAuth account (one auth.users row) can be associated with multiple public.users rows across different tenants. The user has a separate identity, memory, and CRM context in each tenant. UI offers a tenant context switcher when applicable.
