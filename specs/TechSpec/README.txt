AI Travel Concierge Platform — Technical Specification v6.2 (HTML)
================================================================

This directory contains the v6.2 spec rendered as a navigable HTML site.

How to use:
  - Open index.html to start
  - Click any section in the Table of Contents to navigate
  - Within sections, cross-references like "§14.0" or "§26.3a" are
    clickable and jump to the referenced subsection
  - Each section has prev/next navigation at the bottom
  - All ASCII flow diagrams, tables, and code blocks are preserved

Files:
  - index.html                                Entry point with full TOC
  - styles.css                                Shared dark-theme stylesheet
  - section-NN-<title>.html                   One file per section (1-32)

Best viewed in any modern browser. Works offline; no JavaScript required.
