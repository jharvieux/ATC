# Rebuild `/for-agencies` — repositioning + restyle spec

**Repo:** the AI Travel Concierge site (the same codebase that ships the consumer app at `ai-travel-concierge-tawny.vercel.app`).
**Page to change:** `/for-agencies`.
**One-line goal:** Lead with the *outcomes* that make an agent buy — **time saved**, **looking like a bigger operation**, and **research done for them** — and restyle the page to match the consumer app (light + dark themes). Demote "keep your host / keep your commissions" from the headline to a single trust line + one FAQ. It's table stakes, not a selling point.

---

## 0. Do this first — reuse the existing design system

Before writing any markup, read the consumer app and **reuse its actual primitives** so the for-agencies page looks like it shipped from the same codebase:

- Theme tokens / CSS variables (or `tailwind.config` colors) for light **and** dark.
- The light/dark mechanism (e.g. `next-themes`) — wire the same toggle into the for-agencies nav and persist the choice; respect `prefers-color-scheme` on first load.
- Font families already loaded (display, body, mono). Do **not** introduce Inter/Roboto/Arial.
- Existing Button, Card, Badge/Tag, and the **agent card** component (used on the consumer "Meet Your AI Travel Agents" page) — reuse the agent card for the AI-crew section here.

**Brand fallback** (only if a token isn't exposed):

| Role | Light | Dark |
|---|---|---|
| Ink / navy | `#0A2342` | `#EAF2FA` |
| Accent / sky | `#2E92D6` (links) · `#5DADE2` (brand) | `#5DADE2` |
| Background | `#FBFAF7` | `#071626` |
| Surface / card | `#FFFFFF` | `#0C2138` |
| Border | `#E7E0D4` | `#1C3A57` |
| Success | `#1E8A5B` | `#5BD49B` |

Type fallback: one serif display (e.g. Spectral) + one humanist sans body (e.g. Plus Jakarta Sans) + one mono for domains/CRM/step-numbers (e.g. JetBrains Mono). **Defer to the reference site's real fonts if they differ.**

Component guidance: solid-accent primary button (navy on light / sky on dark), bordered ghost secondary, ~11px radius; cards with 1px token border + soft shadow + 16px radius; **one** sky accent per section (eyebrow / emphasis / a 3px top-rule), no full-bleed gradient backgrounds; use the white/reverse logo mark on dark.

## 3. Guardrails

- **Do not change host/commission *mechanics*** — only the messaging weight. The product still brings-your-own-host; we're just not leading with it.
- **Keep every existing mockup**: hero chat, CRM table, side-by-side quote, the 90/7/1-day pre-cruise email sequence, and the supervisor/safety chips. Restyle to tokens; don't remove.
- **Ship working light AND dark.** Test both. Persist the user's choice and respect system preference on first paint (no flash of wrong theme).
- **Accessibility:** maintain AA contrast in both themes; CTA hit targets ≥ 44px; honor `prefers-reduced-motion` for any entrance animation.
- **Don't invent proof.** No fake testimonials, logos, or stats — keep it benefit-led until real proof exists.
- **Keep it minimal.** One accent per section, no gradient-wash backgrounds, no emoji.
